# 3D models for the hub

CC0 only (no on-screen credit is shown; see docs/claude-planning/15-credits.md and
record the source there). Binary glTF (`.glb`), ideally under 2 MB, Y up, any scale
(the scene measures and fits it).

- `bike.glb` — the rider's bike. Replaces the built-in stylised bike when present.

Then run `npm run hub:media` (also runs on `npm run dev` / build).
