# Engineer screenshots for the hub

Drop your own editor screenshots here (your VS Code / Cursor, your code). Strip
emails, tokens, account names. WebP or PNG, 16:10 reads best on the laptop
(e.g. 1600 × 1000). Suggested names:

- `vscode-1.webp` — shown on the laptop's screen
- `vscode-2.webp`, `vscode-3.webp` — spare, for the drifting panes later

Then set `LAPTOP_SCREEN_SRC` in `app/components/hub/vr/screens.ts` to
`/hub/engineer/vscode-1.webp` (or tell Claude the file name).
