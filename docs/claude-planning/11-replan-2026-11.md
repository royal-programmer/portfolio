## Guiding rules for the polish push

1. **Content first, 3D second.** Every page must read fully without WebGL
   (SEO, a11y, slow phones). 3D is a progressive layer that loads after content.
2. **One shared scene engine, one world per persona.** Same tokens/motion
   primitives; each persona composes its own world (extends D20 "shared design
   system, unique per-persona layout").
3. **Performance budget is a feature.** Target Lighthouse ≥ 90 on mobile for
   content pages; 3D lazy-loaded per persona; `prefers-reduced-motion` → static.
4. **Polish one persona to "award" level before widening.** Engineer is the
   reference; others copy its patterns.
